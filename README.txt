JAVA PRACTICAL PROGRAMS (Q1–Q25)

How to use:
1. Extract this folder/ZIP.
2. Open a .java file in VS Code or another Java editor.
3. Compile and run from the folder containing the file:
      javac Q1_SumOfDigits.java
      java Q1_SumOfDigits
4. Q12 uses a package, so compile/run it from the Java_Practical_Programs folder:
      javac Sun/Stars.java Sun/Planet.java Q12_Satellite.java
      java Q12_Satellite

Notes:
- Each Q1–Q25 program is kept in its own file (Q12 also has two package files).
- Q5's pattern image was not included in the question, so a simple star triangle pattern is used. Replace it if your practical question has a different pattern.
- These are beginner-friendly sample programs. Enter the sample inputs shown in the comments or prompts.
